# Other runtimes (untested)

These are versions of the five custom skills for Cursor (`cursor/`) and Claude Code (`claude-code/`). They follow the same rules as the Genie skills in `skills/`, with the Genie-specific parts replaced.

They are untested. I did not run them in Cursor or Claude Code, and the live results in [docs/live-results.md](../docs/live-results.md) cover only Genie One and Genie Code. `tests/test_held_out.py` checks that some rules appear in their text, which is not the same as checking how a model follows them.
